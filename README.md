# 🐚 Shell Programming

A collection of beginner-friendly **Shell (Bash) programming** scripts written while learning Linux Shell Scripting. This repository demonstrates the use of loops, arithmetic operations, conditional statements, and user input through simple programming exercises.

Whether you're just getting started with Bash or looking for basic practice problems, this repository can serve as a helpful reference.

---

## 📌 Repository Overview

This repository includes solutions to common Shell Programming exercises, such as:

- 🔹 Sum of odd numbers from 1 to 100
- 🔹 Numbers divisible by both 3 and 5
- 🔹 Multiples of 8 less than 100
- 🔹 Average of the first 20 natural numbers
- 🔹 Multiplication table of 13
- 🔹 Even numbers from 2 to 20
- 🔹 Sum of the first 10 natural numbers
- 🔹 Factorial of a given number
- 🔹 And more practice problems...

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/gazishawon999/shell-programming.git
```

### Move into the Project Directory

```bash
cd shell-programming
```

### Run a Script

```bash
bash filename.sh
```

or make it executable:

```bash
chmod +x filename.sh
./filename.sh
```
